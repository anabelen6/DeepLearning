## 📌 Overview
This repository contains a complete Deep Learning pipeline for the automatic semantic segmentation of pelvic floor structures in ultrasound images. The primary objective is to facilitate clinical workflows and reduce the time required for manual analysis by accurately identifying key anatomical structures.

## 📊 Dataset
The project utilizes the **PFUS1 (Pelvic Floor Ultrasound) dataset**, which includes ultrasound images alongside segmentation masks generated by clinical experts.

### Segmented Classes
The model is trained to segment the following anatomical structures, along with the background:
- Pubis
- Urethra
- Bladder
- Uterus
- Vagina
- Anus
- Rectum
- Levator ani muscle

### Data Preprocessing & Splitting
- **Patient-level Splitting:** Data was split by patient (90% training, 10% testing) to ensure that images from the same subject do not appear in both sets, preventing data leakage and ensuring a realistic evaluation of the model's generalization capabilities.
- **Data Augmentation:** To improve generalization and mitigate overfitting, various augmentation techniques were applied, including horizontal/vertical flips, rotations, elastic transformations, brightness/contrast adjustments, and Gaussian noise/blur.

## 🧠 Model Architecture & Methodology
The project explores and compares two configurations based on the **U-Net** architecture:
1. **U-Net + VGG16 (Encoder)**
2. **U-Net + ResNet50 (Encoder)**

### Training Configuration
- **Optimizer:** Adam
- **Initial Learning Rate:** 0.0001 (with `ReduceLROnPlateau` for automatic reduction)
- **Loss Function:** Weighted Dice Loss (chosen to handle significant class imbalances, such as the uterus taking up ~30% of pixels while others take <5%)
- **Early Stopping:** Patience of 5 epochs

## 📈 Results
The **U-Net + ResNet50** configuration yielded the best overall results, successfully learning complex features thanks to its residual connections. 

**ResNet50 Test Set Performance:**
- **Mean Dice Score:** 0.765
- **Mean IoU:** 0.621

**Key Qualitative Observations:**
- Structures with consistent shapes like the **bladder** and **levator ani muscle** achieved the highest accuracy.
- Structures with high anatomical variability and less defined borders, such as the **uterus** and **rectum**, presented the most challenges.
- Boundary confusion occasionally occurred in areas where multiple structures are closely grouped or in lower-contrast images.

## 🚀 Future Work
